
## Using a skill

Copy a skill folder into your agent's skills directory (for example `~/.agents/skills/` or `~/.claude/skills/`), then reference it by name. Each `SKILL.md` describes when the skill applies and how to use it.

## Attribution

These are installed copies of publicly available agent skills. Each skill may carry its own license or attribution requirements; review the individual skill before redistributing it.
