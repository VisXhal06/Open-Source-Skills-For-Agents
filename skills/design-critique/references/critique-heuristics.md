# Critique Heuristics

## Clarity

- Can a new user tell what this is in three seconds?
- Is the primary action obvious?
- Is the value proposition specific?
- Is the language plain?
- Is there one idea per section?

## Hierarchy

- What is first, second, third?
- Is size doing the work, or is everything competing?
- Is color used semantically?
- Is spacing grouping related items?
- Is there a clear reading order?
- Is there one memorable moment?

## Affordance

- Does it look interactive before hover?
- Are links distinguishable from buttons?
- Are disabled states clear?
- Are touch targets large enough?
- Is the cursor appropriate?

## Feedback

- Does every action have a response?
- Is loading visible after 100 ms?
- Is success confirmed?
- Are errors explained and fixable?
- Is progress shown for long tasks?
- Can the user cancel?

## Consistency

- Do similar things look and behave similarly?
- Are labels consistent across the flow?
- Are components reused?
- Do Figma and code match?
- Are platform conventions respected?

## Error prevention

- Are destructive actions confirmed or undoable?
- Are inputs validated before submit?
- Are constraints explained?
- Are defaults safe?
- Is data preserved on failure?

## Cognitive load

- How many choices per screen?
- Is progressive disclosure used?
- Is there unnecessary repetition?
- Is the user asked to remember too much?
- Is the content scannable?

## Accessibility

- Keyboard path.
- Focus visibility.
- Labels.
- Contrast.
- Target size.
- Reduced motion.
- Screen reader.
- Zoom.
- Color independence.
- Error announcement.

## Responsive

- 320px.
- 375px.
- 768px.
- 1024px.
- 1440px.
- 1920px.
- Landscape.
- 200% zoom.
- Large text.
- Touch and pointer.

## Motion

- Purpose.
- Timing.
- Easing.
- Choreography.
- Interruption.
- Reduced motion.
- Performance.
- No scroll-jacking.
- No flashing.

## Performance

- LCP.
- INP.
- CLS.
- Images.
- Fonts.
- JS.
- Third parties.
- Animation.
- Long lists.

## Content

- Truth.
- Specificity.
- Voice.
- CTA clarity.
- Error copy.
- Empty state copy.
- No filler.
- No placeholder links.

## Trust

- Is there proof?
- Is pricing clear?
- Is security visible where needed?
- Are claims credible?
- Are there dark patterns?
- Is the user in control?

## Originality

- Is this specific to the subject?
- What is generic?
- What is the one memorable idea?
- Is the direction coherent?
- What can be removed?
