# Onboarding

## Day 1

- [ ] Access to repository, issue tracker, and communication tools.
- [ ] Install dependencies and run the app locally.
- [ ] Read `README.md` and `AGENTS.md`.
- [ ] Meet the owner and ask how work is prioritized.

## Week 1

- [ ] Architecture walkthrough.
- [ ] Run the test suite.
- [ ] Ship one small change end to end.
- [ ] Review one pull request.
- [ ] Read the last three ADRs.

## First month

- [ ] Own a feature from brief to production.
- [ ] Lead a code review.
- [ ] Update one stale document.
- [ ] Present what you learned.
